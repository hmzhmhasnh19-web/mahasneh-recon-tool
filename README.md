## 📌 Features

- **Fast Multi-Threaded Port Scanning:** Scans critical infrastructure ports concurrently using `ThreadPoolExecutor`.
- **HTTP/HTTPS Service Inspection:** Analyzes Web server HTTP status codes and extracts `Server` response headers.
- **Auto Hostname Resolution:** Automatically converts target domains/URLs to IPv4 addresses.
- **Graceful Error Handling:** Keyboard interrupt detection (`Ctrl+C`) and network timeout controls.
- **Terminal UI:** Color-coded terminal output powered by `colorama`.
